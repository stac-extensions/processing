# Guidance for AI agents

This repository contains the specification of the STAC Processing extension. It contains no application code.

- Read [README.md](README.md) and [CONTRIBUTING.md](CONTRIBUTING.md) before you propose, write or review a change.
  The README is the specification. The contributing rules apply to you as they apply to human contributors.
- The [Scope section of the README](README.md#scope) is the authority for what belongs in this extension.
  If a request is out of scope, say so and give the reason. Do not implement it in a different form.
- Do not guess. If the specification or the data provider does not give a value, do not invent one.
  This includes processing levels, versions and identifiers.
- Run `npm test` before you say that a change is complete.
